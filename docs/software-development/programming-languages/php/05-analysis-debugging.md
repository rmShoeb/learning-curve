# Static Analysis & Debugging Techniques

5.1 Code Flow Tracing Strategies

Following execution entry points (index.php, entry scripts, bootstrap files)

Tracing dependency injection or singleton instances across files

Locating global configurations and environment variable loading (.env or custom global configs)

5.2 Static Analysis & Code Reading Tools

Reading DocBlocks and PHPDoc comments (@param, @return, @throws)

Utilizing static analysis IDE features (PHPStorm, VS Code PHP Intelephense)

Understanding PHPStan / Psalm annotations if present in the legacy code base
