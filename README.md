# Learning Curve

This repository contains various learning materials, code examples, and projects across different programming languages and technologies.

## Repository Structure

### C++ STL
- Examples demonstrating Standard Template Library usage including:
  - Complex numbers
  - Lists
  - Maps
  - Pairs
  - Sets
  - Stacks
  - Vectors

### Database
- RDBMS Concepts Guide
- MS SQL Server examples including:
  - Scalar functions
  - Stored procedures
  - Table-valued functions
  - Cinema hall database example

### Java
- Core Java examples
- File handling and data streams
- Java Swing GUI applications
  - Form handling
  - Event listeners
  - Custom panels and toolbars

### LaTeX
- Beamer presentation examples
- PDF generation

### Machine Learning
- Jupyter notebooks covering:
  - Categorical variables
  - Code language prediction
  - Classification projects
  - Data science templates
  - Pipeline examples
- Deep Learning topics:
  - TensorFlow
  - Graph Neural Networks
  - Transformer models
  - Tabular data analysis
- Special Projects:
  - No Actual Classifier implementations
  - Titanic dataset analysis

### Python
- OS module examples
- Desktop application development
  - TKinter framework
- Regular expressions
- Image processing

### Web Development
- Various web technologies:
  - AngularJS
  - DOM manipulation
  - Flask (Python web framework)
  - HTML/CSS/JavaScript projects
  - PHP
  - Servlet/JSP
  - Spring Framework
  - Basic CRUD applications

## Purpose

This repository serves as a learning resource and reference for various programming concepts, frameworks, and technologies. Each directory contains practical examples and implementations to help understand different aspects of software development.

## Technologies Used

- Languages: C++, Java, Python, JavaScript, PHP, SQL
- Frameworks: Spring, Flask, AngularJS
- Libraries: STL (C++), Swing (Java), TKinter (Python)
- Machine Learning: TensorFlow, Scikit-learn
- Other: LaTeX, HTML/CSS

## Getting Started

Each directory contains its own set of examples and projects. Navigate to the specific technology or concept you're interested in to find relevant code and documentation.
